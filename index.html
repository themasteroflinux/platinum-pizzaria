Keep Android Open

myPP is distributed independently through Obtainium, which helps install the app and deliver updates directly from its GitHub releases. Android developer verification restrictions could make independent distribution harder or prevent tools like Obtainium from installing or updating apps.

No Obtainium means no straightforward way to distribute and update myPP. If these restrictions take effect in a way that blocks Obtainium, the myPP app may no longer be available through our current installation method. Online ordering through this website will remain the alternative.

Platinum Pizzaria supports the right to install apps from sources users choose. We do not support restrictions that undermine independent Android app distribution.
